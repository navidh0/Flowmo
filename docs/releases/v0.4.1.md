# Flowdo 0.4.1 — the mini widget behaves on Windows

**The mini widget no longer gets stuck open.** On Windows, minimizing and restoring Flowdo quickly (a double-click on the taskbar icon is enough) could leave the small timer on screen after the main window came back, and it stayed there until you turned it off. Flowdo now checks whether the window is actually minimized instead of trusting the order Windows reports events in.

**A widget you just dragged keeps its spot.** If you moved the mini widget and quit Flowdo within a fraction of a second, the new position could be lost. It's now always saved.

**Your data** stays in `%APPDATA%\Flowdo` on Windows and `~/.config/Flowdo` on Linux. Updating does not touch it. If you're on 0.4.0, Flowdo updates itself; open Settings → Updates to check now.

**The installers are unsigned.** On Windows, SmartScreen will show "Windows protected your PC": choose **More info**, then **Run anyway**.
