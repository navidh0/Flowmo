# Flowdo 0.4.2 — a close button on the widget, and the taskbar icon is back

**The mini widget now has a close button.** The small timer that appears when you minimize the window was frameless, so there was no way to close it from the widget itself. It now has a small close button (×) in its top-right corner. Closing it this way counts as your choice: a widget that opened because you minimized the window won't pop back up until the window next leaves the screen. You can reopen it from the tray, or turn it on in Settings.

**The taskbar icon is back on Windows.** Some installs showed a blank placeholder icon in the taskbar instead of Flowdo's icon. Both windows now carry the icon themselves, so it no longer depends on a Start-menu shortcut. On Linux, window managers that showed no icon for Flowdo's windows now show it too. If the blank icon persists after updating, it comes from Windows' own icon cache or an old pinned shortcut: unpin Flowdo from the taskbar and pin it again.

**Under the hood:** Flowdo now runs on Electron 44 (from 43).

**Your data** stays in `%APPDATA%\Flowdo` on Windows and `~/.config/Flowdo` on Linux. Updating does not touch it. If you're on 0.4.0 or 0.4.1, Flowdo updates itself; open Settings → Updates to check now.

**The installers are unsigned.** On Windows, SmartScreen will show "Windows protected your PC": choose **More info**, then **Run anyway**.
