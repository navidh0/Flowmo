# Flowdo 0.5.1 — the taskbar icon and the widget's close button, properly this time

**The taskbar icon, Start menu shortcut, and desktop shortcut now show the Flowdo logo.** Version 0.4.2 tried to fix the blank Windows taskbar icon by giving both windows their icon. That fixed the title bar, but the taskbar button kept showing a blank placeholder. The real cause was in the icon embedded in Flowdo.exe: it stored every size as a compressed PNG, and Windows can't read those at the small sizes the taskbar, Start menu and shortcuts use. Flowdo now ships with a Windows icon that has classic bitmap images at those small sizes, so the taskbar button, Start menu listing and desktop shortcut all show the Flowdo logo. If the blank icon persists right after updating, Windows is showing a cached copy from an older install; unpin Flowdo from the taskbar and pin it again, or sign out and back in.

**The mini widget's close button works.** The × added in 0.4.2 sat in the widget's very corner, where Windows treats the window edge as a resize handle and the rest of the widget as a drag area, so clicking it did nothing. It now sits at the end of the top row, next to the phase name, clear of the edges, and a click closes the widget.

**Nothing else changed.**

**Your data** stays in `%APPDATA%\Flowdo` on Windows and `~/.config/Flowdo` on Linux. Updating does not touch it. If you're on 0.4.x or 0.5.0, Flowdo updates itself; open Settings → Updates to check now.

**The installers are unsigned.** On Windows, SmartScreen will show "Windows protected your PC": choose **More info**, then **Run anyway**.
