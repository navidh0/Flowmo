# Flowdo 0.5.3 — Sync now, one click

**The Today view now has a Sync now button in the header.** One click pulls Todoist and refreshes your calendar feeds at the same time, without opening Settings. It shows "Syncing…" while working and reports the result in its tooltip: "Synced just now" if both succeeded, or which side failed if one didn't. The button's icon turns red on failure until the next successful sync. It's hidden when neither Todoist nor any calendar feed is connected. Settings → Integrations keeps its own Sync now and Refresh now buttons for when you want to sync just one side.

**Behind the scenes, the CI/CD pipeline is faster.** Each PR push triggers one CI run instead of two, with one packaged end-to-end test per platform. Releases now run the full installer matrix once and publish the builds they tested, instead of building twice. A flaky mini-widget e2e check (a stale closed widget page) was also fixed.

**Nothing else changed.**

**Your data** stays in `%APPDATA%\Flowdo` on Windows and `~/.config/Flowdo` on Linux. Updating does not touch it. If you're on 0.4.x or 0.5.x, Flowdo updates itself; open Settings → Updates to check now.

**The installers are unsigned.** On Windows, SmartScreen will show "Windows protected your PC": choose **More info**, then **Run anyway**.
